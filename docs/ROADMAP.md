## 🧪 进行中 / 近期

### 文字夹私货 `contact-obfuscator`
- **定位**：联系方式防机器识别变换器。可见字符多样化随机变换为主（大小写、穿插符号/表情/汉字、数字转中文、可见分隔符），可选不可见字符（零宽/同形字）作激进层。
- **范式**：纯本地确定性变换（无 AI 回填），4 档预设 + 全独立开关，一次出 3 条候选，设置与历史 localStorage 记忆。
- **边界**：不可见字符默认关闭 + 醒目警示（部分平台会规范化过滤）；顶部明确「合规前提下使用」。

## 💡 候选池（按契合度排序）

### 第一梯队（高复用现有范式，落地最快）

#### 1. SVG 图标 / Logo 生成器 `svg-icon-generator`
- **契合范式**：`代码回填 + dryRun`（复用 quote-card 动画 / qr-code 码点的三步模态骨架，改造量最小）。
- **玩法**：用户描述需求 → 工具组装提示词（注入当前配色/尺寸约束）→ AI 返回 `<svg>` → 粘回 → `DOMParser` 校验合法 SVG（查 `<svg` 标签、`viewBox`、无 `<script`）→ 预览 + 存「我的图标库」（localStorage，可重命名/删除/导出 SVG/PNG）。
- **联动**：接收 color-extractor/color-prompt 的色板作为约束，生成图标天然配色一致。
- **技术风险**：极低，SVG 解析/渲染全是浏览器原生。

#### 2. CSS 渐变 / 背景生成器 `gradient-generator`
- **契合范式**：`代码回填 + 套用模板`（与 qr-code「配色 apply + 码点代码」二段式结构同构）。
- **玩法**：本地拖拽调 stops/角度实时预览；AI 路径描述「极光/Stripe mesh/日落沙漠」→ 提示词约束只用 `linear/radial/conic-gradient` + CSS 变量 → AI 返回 → 粘回预览 + 存「渐变库」（⭐ 前缀，可删，刷新还在）。
- **进阶**：支持 AI 生成完整 `background-image`（多层叠加 + SVG 噪点 data URI），工具逐层可视化拆解。

#### 3. 正则表达式可视化器 `regex-tester`
- **契合范式**：`提示词组装 + 回填 + 即时反馈`。
- **玩法**：粘贴测试文本 + 输入正则 → 实时高亮匹配/分组/替换结果（纯浏览器 `RegExp`）。AI 双向：① 描述需求 → 提示词（带测试样例）→ AI 返回正则 → 回填自动跑；② 粘看不懂的正则 → 提示词让 AI 解释。
- **创新**：双向 AI 协作（生成 + 反向解释），别家少见。

### 第二梯队（趣味向，易传播）

#### 4. 头像 / 像素画生成器 `avatar-generator`
- 与 SVG 图标生成器技术栈高度重合，可共用回填+预览+图库骨架。描述「戴眼镜的橘猫程序员」→ AI 生成像素画指令 → 分层渲染 → 导出 PNG。

#### 5. ASCII / emoji 艺术生成器 `ascii-art`
- 本地 figlet 风格字体即时预览；AI 路径描述「把『新年快乐』排成灯笼形状」→ AI 生成 ASCII/emoji 排版 → 回填。轻量、纯文本、传播性强。

#### 6. 网名 / 频道名生成器 `name-generator`
- 复用 password-generator 提示词组装范式，产物是创意名字。内置本地词库即时随机 + AI 主题化路径。

### 第三梯队（实用向，补全版图）

#### 7. JSON / 数据格式转换器 `data-converter`
- **本地**：JSON ↔ CSV ↔ YAML ↔ TypeScript 接口（纯 JS 解析）。
- **AI 增值**：粘杂乱 JSON → 提示词让 AI「推结构、生成 TS 类型 + 示例 + 字段中文注释」→ 回填编辑器。差异化亮点。

#### 8. Markdown / 公众号排版器 `markdown-styler`
- 纯本地 Markdown 解析 + 主题样式（可复用 quote-card 卡片样式系统）。AI 路径：描述风格 → AI 生成 CSS → 回填套用实时预览。反向：公众号 HTML → AI 转干净 Markdown。

#### 9. Cron 表达式生成器 `cron-helper`
- 描述「每个工作日早 9 点」「每月最后一个周五」→ AI 生成 cron → 回填可视化解析（列出下次触发时间）。补全开发者工具版图。

## 🎨 跨工具联动（杀手级创新）

### 全局「我的风格档案」`brand-profile`
- **定位**：一个贯穿全站的品牌风格中枢（首页侧栏或独立工具），存「我的品牌色板 + 字体偏好 + Logo SVG + 渐变库」。
- **机制**：所有工具的 AI 提示词自动 `injectBrandIntoPrompt(prompt)` 注入这套档案——qr-code 码点配色、SVG 图标颜色、CSS 渐变背景、名言卡片主题色，全部来自同一份档案，**保证全站产出物风格统一**。
- **价值**：把分散的「单工具 AI 提示词」升级成「带品牌一致性的 AI 创作流」，是别家没有的差异化。
- **实现**：复用 localStorage 一份全局 versioned blob + 一个共享的提示词注入工具函数（放 `src/core/utils/`）。
- **依赖**：需要先有 2-3 个接受注入的工具（color-* 已具备，svg/gradient 落地后形成闭环）。

## 落地优先级建议

1. **先做 SVG 图标生成器**——复用 quote-card 三步模态骨架改造量最小，AI 产出 SVG 成功率高，首次体验好；且与 color-* 天然联动，立刻体现「中枢」雏形。
2. **顺带做 CSS 渐变生成器**——同一套回填骨架换个渲染器，边际成本低。
3. **积累 3 个接受注入的工具后**，启动「我的风格档案」联动层。
4. 趣味向（头像/ASCII）和实用向（数据转换/排版器）按精力穿插。

## 每条候选的评估维度

新增候选工具时，建议回答以下问题再决定是否启动：

- **契合范式**：能否复用现有的「提示词单向 / 代码回填 + dryRun / 本地确定性」三种范式之一？
- **AI 角色**：是 AI 生成内容回填，还是只组装提示词让用户带走，或完全不需要 AI？
- **联动性**：能否被「我的风格档案」注入，或消费其他工具的产出？
- **技术风险**：是否纯浏览器可实现？有无需引入重依赖（如 wasm）？
- **传播性**：产出物是否值得分享（图片/代码/文本）？
- **合规边界**：是否有滥用风险（如本次 contact-obfuscator 需明确「合规前提下使用」）？
